# Citation Management Setup

This document provides instructions for installing Zotero or Mendeley citation management tools.

## Zotero Installation

1. Download Zotero from https://www.zotero.org/
2. Run the installer and follow the setup instructions
3. Install the browser extension for your web browser
4. Configure the Microsoft Word or Google Docs plugin if needed

## Mendeley Installation

1. Download Mendeley from https://www.mendeley.com/
2. Run the installer and follow the setup instructions
3. Install the browser extension for your web browser
4. Configure the Microsoft Word or Google Docs plugin if needed

## APA 7th Edition Citation Style Setup

Both Zotero and Mendeley support APA 7th edition citation styles. After installation:

1. For Zotero:
   - Open Zotero preferences (Edit > Preferences)
   - Go to Cite tab
   - Check if APA 7th edition is available in the dropdown
   - If not, install it from the styles repository

2. For Mendeley:
   - Open Mendeley Desktop
   - Go to Tools > Options > Citations
   - Select APA 7th edition from the style list
